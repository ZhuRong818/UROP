# Proposed release policy and rights inventory

This is an internal artifact inventory, not legal advice or permission to publish.

| Artifact class | Proposed public artifact | Present rights state |
|---|---|---|
| Authored manuscript, diagrams and prose | Paper and aggregate-comparison figures | Author/contribution approval and venue requirements pending |
| Research implementation | Narrow reproducibility bundle with locked versions and source adapters | No root repository license file was found in this inventory; code ownership/license decision pending |
| Aggregate metrics and source hashes | Cohort-separated tables, manifests and permitted summaries | Provider/venue agreement review required before public release |
| Lumid article text, provider payloads and contract-rule bytes | Keep out of the proposed public bundle | Redistribution permission not established; local review packets contain these bytes |
| Reviewer submissions and identities | Consented pseudonymous labels or aggregate agreement only | Reviewers not assigned; consent and anonymity preferences pending |
| Future V4 protected records | Only permitted post-gate aggregate result | Frozen collection/consumption/evaluation gates apply; no early release |

Proposed bundle: authored paper, figures, approved aggregate tables, code with an explicit license, package/version declarations, source/query schema descriptions and hashes. Provide source acquisition instructions rather than article text. Keep credentials, raw API responses, wallets/account identifiers and protected payloads out of that bundle. Hashes identify bytes; they do not establish redistribution rights.

Outstanding evidence: provider terms/permission for aggregate release, code ownership/license, author approval, reviewer consent and venue policy. No publication, upload or external transmission has occurred. The local review packet is usable now without claiming public-release clearance.
