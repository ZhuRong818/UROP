## Method decision for a successor working revision

Recommend the primary research question be **incremental value of verified relevant content over market state plus content-neutral news timing**, with novelty a secondary nested mechanism. The existing T shares a semantic link gate, so its R–T/N–T contrast answers only what added features contribute conditional on that gate. A successor implementation should define T using arrival times/counts from the declared source feed and non-text source metadata only, independent of headline, summary, rules and semantic-link output. R adds certified semantic relevance/claim-role/applicability features to that same row set; N adds prior-history novelty. Freeze exact exposure functions, nesting, loss contrast and multiplicity before evaluation. This is a proposal, not an edit to the current working plan or a fitted model.

Retain the 30-minute target, strong market-only M, fold-local out-of-fold offset training, common evaluation rows and one-shot separation. No inference method is currently qualified: prior grouped-t/block screens undercovered persistent and regime-shift simulations. Before a new freeze, simulate the chosen synchronized event/time dependence design over plausible missingness and exposure concentration using development-only parameters; require nominal coverage and usable power for the predeclared gain. Row count alone is never a power proxy.
